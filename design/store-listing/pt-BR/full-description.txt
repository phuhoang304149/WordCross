Word Crossy é um jogo de palavras que une deslizar pelas letras e cruzadinha. Deslize o dedo pelas letras da roda para formar uma palavra e veja ela encaixar no tabuleiro. Preencha todos os espaços para vencer a fase e seguir para a próxima.

COMO JOGAR
• Deslize pelas letras da roda para formar palavras
• Cada palavra certa ocupa seu lugar na cruzadinha
• Encontre todas as palavras do tabuleiro para vencer a fase
• Embaralhe as letras quando quiser para vê-las de outro jeito

TRAVOU? USE UMA DICA
• Uma dica revela uma letra no tabuleiro
• As dicas custam rubis, mas nunca são obrigatórias para terminar uma fase
• Ganhe rubis ao vencer uma fase pela primeira vez

PALAVRAS EXTRAS
Algumas palavras que você formar não estarão no tabuleiro, mas podem ser válidas. Encontre essas palavras extras e resgate uma recompensa em rubis. Cada palavra extra conta uma vez por fase.

DESAFIO DIÁRIO
Volte todos os dias para resolver um tabuleiro novo. Complete para ganhar uma recompensa e montar uma sequência de dias, com bônus nos marcos da sequência.

MUNDOS PARA EXPLORAR
Escolha um mundo e depois uma fase. Deslize para trocar de mundo e ver onde você pode jogar em seguida.

COMPRAS NO APP E ANÚNCIOS
Word Crossy é grátis e tem anúncios. Há compras opcionais dentro do app, como pacotes de rubis e uma opção para remover os anúncios. Algumas recompensas vêm de assistir a um vídeo, sempre por escolha sua.
